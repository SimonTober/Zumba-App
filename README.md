# Zumba Planer

Persönliche Kursassistentin für Zumba-Stunden – eine einzige statische Web-App (kein Build nötig).

- **Stunde planen**: 30 / 45 / 55 / 60 Minuten, Intensität wählbar, Favoriten bevorzugen, Übungen tauschen
- **Kursmodus**: geführter Timer durch alle Übungen, Ton/Vibration, Bildschirm bleibt an
- **Übungsbibliothek** mit Suche, Anleitungen und YouTube-Links
- **Verlauf** mit Statistik, Bewertung und Notizen; **Favoriten**
- Hell/Dunkel, Drucken/Kopieren, offlinefähig und als App installierbar (PWA)

Lokal testen: `python3 -m http.server` und `index.html` öffnen (der Service Worker braucht http/https).
